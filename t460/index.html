Two agents from the same office on your side? That's Form AAA.

Form AAA puts every agent of one brokerage who works your side into the contract, so wherever one name appears, the others count too.

↑Top of the form: which agreement it attaches to

AAA never stands alone. It is an addendum to another agreement. The default is the Purchase Agreement; to attach it to a Listing Agreement, a Buyer Representation Agreement or something else, you check that box. Then the date of that agreement, the property, and the two sides. The form says "Housing Provider" also means a landlord, so AAA works for rentals too. Note: in California a buyer representation agreement can last at most 3 months, and each renewal also at most 3 months, in writing (Civil Code §1670.50, AB 2992, since 1/1/2025). Adding agents does not change that.

Example: Seller A signs a listing on 12/01/2026 for 1234 Example Lane, San Jose, CA 95100. Agent X and Agent Z will both work it. AAA: attached to the Listing Agreement dated 12/01/2026, between Brokerage Y and Seller A.

1Check ONE box only

Box A: several agents working with the seller (or landlord). Box B: several agents working with the buyer (or tenant). Only one box. If both sides have agent teams, each side uses its own AAA.

Think of it like a soccer roster: each team writes its own list. The seller side of 1234 Example Lane has Agent X and Agent Z, so they check box A.

2AAll under the same broker

Every agent on this form does licensed work under the same broker. You write the broker's name, and the team name if there is one. Agents from two different brokerages don't use AAA; that is Form ABA.

Example: Agent X and Agent Z are both with Brokerage Y, on "Team Example". 2A reads: Brokerage Y, Team Example.

2BTheir own written deal on work and pay

The agents state that they have signed a separate written agreement with each other to share responsibility and pay for this work, and that they told the broker about it or gave the broker a copy. That agreement is between the agents. AAA itself has no dollar amount anywhere.

Example: Agent X handles pricing and negotiation, Agent Z handles open houses and paperwork, and they split pay by their own paper. Seller A still pays exactly what the listing says.

2CList ALL the agents

Name and DRE license number for each agent. There are 5 lines; more than that, check "Additional Licensees" and add them. Agents already named in the main agreement may be listed again, but they don't have to be.

Example: Line 1: Agent X, DRE #0000001. Line 2: Agent Z, DRE #0000002. (Real DRE numbers have 8 digits; these are made up.)

3One name counts for all

Wherever the agreement or a related document names one of these agents as the representative of the buyer/tenant or seller/landlord, the other agents are treated as named too. The note under it: if AAA only changes a Buyer Representation Agreement, the seller and the seller's broker don't sign; if it only changes a Listing Agreement, the buyer and the buyer's broker don't sign.

Example: The listing for 1234 Example Lane only names Agent X. With the AAA, every place that says Agent X also counts as saying Agent Z.

✎Signatures

Signing means you got a copy, read it, understand it and agree. There are lines for two buyers/tenants, two sellers/landlords, and each side's brokerage firm, signed "By" a person with a DRE number. Who can skip signing is in the note under paragraph 3.

Example: AAA on the listing for 1234 Example Lane: Seller A signs, Brokerage Y signs "By" Agent X. There is no buyer yet, and none is needed.

    What many people get wrong

    "Same office, so no paperwork needed." Wrong. Two agents working together without an AAA means only one of them is your agent on paper. The other one calls, takes offers, talks price, and on paper stands outside. In 23 years the fights I've seen rarely start with the client. They start with two agents who split the work by handshake.

    "AAA means I pay more." No. AAA has no box for money. You pay what your listing or buyer agreement says. How the agents split it is their own paper (2B).

    "Both sides have teams, so one AAA covers it." The form says no. Paragraph 1 allows one box; two sides means two sheets.
