    Next steps

    1. Check the credential first: InterNACHI, ASHI or CREIA. Engineers: BPELSG license lookup. Roofers and plumbers: CSLB.
    2. Book inside your inspection contingency (17 days in the standard C.A.R. contract). Aim to have reports by day 10.
    3. Go to the inspection. Ask the inspector to show you the top 3 issues in person.
    4. Not sure which inspections this house needs? Use T70. Termite: T81.

    Common mistake: Thinking California licenses home inspectors. It does not. There is a practice law (B&P §7195–7199), but no state license. So check membership and training yourself, and ask for a sample report.
