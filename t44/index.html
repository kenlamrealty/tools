Gentle fixes (for reference)

    About the “quẻ Kinh Dịch” method: it is popular for picking phone numbers (split the digits, divide by 8, read the hexagram). It is rarely used for house numbers and people set it up differently, so this tool does not compute it.

    Common mistake: Thinking a “bad” number sinks the price. Price comes from comps, location and condition. Where a number effect was measured, it was small and only in areas where many buyers avoid it.
